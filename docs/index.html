THE CONTRACT

Established theory.
Bounded evidence.

What this is

An ordinary, noncomplemented reduced ordered Boolean decision diagram inspector. At most five declared variables, ten CNF clauses and 120 variable orders. Empty clause is false; empty conjunction is true. Literal integers are signed and 1-based; variable indices elsewhere are 0-based.

Canonical only for a fixed variable order, up to graph isomorphism. We expose low-first construction labels, full prefix reductions, gap-aware exact counting and existential-extension witnesses.

What this is not

No new BDD algorithm, trained model, scalable compiler, formal proof, calibrated uncertainty estimate or real-agent reliability guarantee. This exhaustive educational census does not reproduce the guarantees of formally verified projected-compilation systems.

The separate native checker imports only shared input validation. It uses residual truth-function classes and direct suffix enumeration, not the generator's recursive unique-table builder or graph counting recurrence.

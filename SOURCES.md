# Read sources, November 10,2026
1. Randal Bryant, Graph-Based Algorithms for Boolean Function Manipulation,1986,primary paper. https://www.cs.cmu.edu/~bryant/pubdir/ieeetc86.pdf . Fetched; read definitions/reduction/canonicity/order sensitivity/restriction/counting. Uses noncomplemented graph; original ordering discussion contains dated complexity claims,not reused. Claims: ordered redundant-test removal and equal-subgraph merging,unique up to isomorphism for a fixed order,order size dependence. No implementation copying.
2. Darwiche and Marquis,A Knowledge Compilation Map,JAIR2002,primary AI/KR survey. https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume17/darwiche02a.pdf . Fetched;read introductory scope/decision/order/decomposable/deterministic/smooth definitions. Compilation language trades succinctness against query/transform tractability. Our measured tiny node census is not a general tractability proof or scalable compiler.
3. tulip-control/dd official documentation. https://github.com/tulip-control/dd/blob/main/doc.md . Fetched;read manager semantics,exist/forall/let,pick/count,nvars. Shared reduced ordered BDDs with complemented edges; compare function/model sets and count over explicit care-variable universes,not raw node counts against our noncomplemented graph. Default count is support-based unless nvars supplied. High confidence exact API semantics;actual pinned distribution needed for reference.
4. dd.autoref implementation. https://github.com/tulip-control/dd/blob/main/dd/autoref.py . Fetched;count delegates manager nvars;exist/quantify and let exposed. Code is reference inspection only,not vendored/copied.
5. Bryant et al.,Certifying Projected Knowledge Compilation,SAT2025,primary paper. https://www.cs.cmu.edu/~bryant/pubdir/sat25.pdf . Fetched;read scope/projection/Skolem witness distinctions. Existential removal describes retained assignments with at least one hidden extension; certified projected compilers/formal HOL4 proofs already exist. Our exhaustive replay is not this formal proof framework or its guarantee.
6. Steven Holtzen,CS7480 Scaling Discrete Inference,Northeastern teaching slides,Fall2021 as visible despite URL directory23. https://www.khoury.northeastern.edu/home/sholtzen/assets/teaching/CS7480-23-slides/lec-7.pdf . Fetched;read WMC literal-product sum and compilation-to-circuit motivation. Nonnegative general literal weights need not sum to1; only normalized per-variable weights support independent-Bernoulli probability interpretation.
7. Berkeley Boolean Algebra and Binary Decision Diagrams,course lecture2005. https://people.eecs.berkeley.edu/~keutzer/classes/244fa2005/lectures/12-1-BooleanFunctions.pdf . Fetched;cofactors,Shannon expansion,ordering and symbolic operations. Teaching evidence,not new theory.
8. TU Graz Binary Decision Diagrams and Symbolic Model Checking,academic lecture. https://www.isec.tugraz.at/wp-content/uploads/2020/07/mc08-bdds.pdf . Fetched;existential abstraction is OR of cofactors;order dependence and model-checking context. No liveness/safety claim transferred.
9. dd official README https://github.com/tulip-control/dd/blob/main/README.md . Fetched;multiple backends,quantification,substitution and model enumeration. Reference package should stay optional and separately installed.

## Attribution and implementation boundary

Classical algorithms and theory are credited above. Native,checker and browser code are original bounded implementations. No paper or dd implementation code is vendored. The dd 0.6.0 distribution metadata reports BSD and Python>=3.11. Current published docs may differ from the pinned distribution;actual tests check its installed version. Existing fixed-order canonicity and projected-compilation certification work predate this project. This educational replay is not a new algorithm or a formal certification framework.
